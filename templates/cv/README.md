# Forever Careers standard CV layout (approved by Kenneth, 30 Sep 2026)

Every CV we write for a client uses this layout. Reference build: `reference_build_tade_it_support.js` (docx npm library), which produces the approved example "Tade_Olanrewaju_IT_Support_CV". Copy it, replace the content, keep the styling.

## Page
- A4, one page wherever possible (two pages only for long careers). Margins: top 680, bottom 600, left and right 850 (DXA).
- Font: Calibri throughout. Body 9.5pt (size 19), ink colour #1B2530. Muted text #5B6773. Accent #1F5E7A.
- Deliver both a PDF (for sending) and a Word .docx (for edits). File name: Firstname_Surname_<Target>_CV.pdf / .docx

## Header
1. NAME in capitals, 22pt bold, slight letter spacing.
2. Target title line in accent colour, 12pt bold, for example "Entry Level IT Support and Service Desk | Part Time".
3. Contact line (muted): phone | email | location.
4. Availability line (muted, italic) when relevant, for example "Available for part time, flexible or zero hours work alongside my degree. Remote or hybrid preferred."

## Sections (headings: capitals, accent colour, bold, thin accent rule underneath)
- PROFILE: one paragraph, 4 to 6 lines, first person, honest about level.
- EDUCATION first for students and recent graduates; after EXPERIENCE for everyone else. Degree in progress shows "Expected <year>". Achievements as bullets.
- SKILLS: two column table without borders, each column with a small accent subheading (for example "Developing through my degree" and "From work").
- EXPERIENCE: most recent first. Line 1: job title bold, dates right aligned (muted) written "May 2024 to Present". Line 2: employer | place in muted italics. 2 to 3 bullets each, using the accent bullet style.

## Honesty rules
- Only use facts the client has given us (their CVs, emails, sign up details). Never invent employers, dates, grades, skills or tools.
- Never overstate technical skills: skills still being learned are labelled as developing through study.
- If sources disagree on a date, use the part they agree on (for example the year) and flag it to Kenneth.
- British English. No hyphens or dashes in the text we write (write "to" for date ranges).
